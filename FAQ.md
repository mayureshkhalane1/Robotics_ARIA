# FAQ – ARIA & Webots Compatibility

**Q: Why does `apartment.wbt` appear black or empty when I open it in Webots R2025a?**
A: The original file used EXTERNPROTO references (`webots://...`) and a `#VRML_SIM R2024a` header. R2025a deprecated VRML/X3D, so those resources aren’t loaded. We replaced the file with a pure VRML version (R2023b) that works across versions.

**Q: Do I need to convert the world to W3D?**
A: Not required. Opening the VRML file will show a conversion dialog – you can click **Yes** to generate a `.w3d` file for future‑proofing, or simply click **No** and keep using the VRML file directly.

**Q: Which Webots version should I use for the ARIA demo?**
A: Any version from R2023b onward. For the most recent features, use R2025a. The provided worlds (`house.wbt`, `arena.wbt`, and the new `apartment.wbt`) are all compatible.

**Q: My robot does not move in `apartment.wbt`. Why?**
A: The simplified robot defined here is a static `Solid` (no motor joints). For motion you need the full Pioneer3‑DX proto or implement motor joints manually. The `house.wbt` and `arena.wbt` contain a fully functional robot.

**Q: How can I add more searchable objects?**
A: Add a new `DEF <NAME> Solid` block with a simple geometry (Box, Cylinder, Sphere). Give it a unique `translation` and a distinct colour in the `Material`. The Smart Vision Agent will recognize any object with a `DEF` name.

**Q: My camera feed is black. What can I do?**
A: Ensure the robot’s camera node is present (the placeholder box in `apartment.wbt`). If using the full Pioneer proto, the camera is already configured. Also verify that Ollama is running and the LLM can process images.
