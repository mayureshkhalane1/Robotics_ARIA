# Webots Compatibility Guide for ARIA

## 📌 Problem Overview
- **User's Webots version:** **R2025a** (released Jan 2025)
- **Original world file:** `apartment.wbt` used a **VRML_SIM R2024a** header and **EXTERNPROTO** links to `webots://` resources.
- **R2025a change:** Introduced **W3D** format and **de‑deprecated** VRML/X3D support. Loading a VRML world triggers a conversion dialog or produces warnings.

## ✅ Solution Implemented
We replaced `apartment.wbt` with a **pure VRML (R2023b) file** that:
- Uses only built‑in geometry nodes (`Box`, `Cylinder`, `Sphere`).
- Has **no EXTERNPROTO** references.
- Keeps a header `#VRML_SIM R2023b utf8` which loads in **R2025a** (with a warning) **or any older version**.
- Defines the ARIA robot, floor, lighting, and searchable objects (cup, football, bottle, plant).

## 🚀 How to Load the Updated World
1. **Open Webots (R2025a).**
2. **File → Open World…** and select `src/webots/worlds/apartment.wbt`.
3. Webots may show a dialog: *“Convert this VRML world to the new W3D format?”* – click **Yes** to create `apartment.w3d` **or** click **No** and continue using the VRML file directly.
4. The scene should display:
   - A gray floor
   - Overhead point light
   - ARIA robot (gray body, black camera placeholder, blue GPS placeholder, wheels)
   - Red cup, green football, blue bottle, green plant – all searchable via the Smart Vision Agent.

## 🛠️ Adding More Objects
1. **Create a DEF node** using `Solid`.
2. Choose a simple geometry (`Box`, `Cylinder`, `Sphere`).
3. Set `translation` to position it in the world.
4. Add a `Shape` with an `Appearance` → `Material` for colour.
5. Add a matching `boundingObject` and a small `Physics` mass.
6. Ensure the node name (e.g., `DEF NEWOBJ`) matches the object name used in prompts (`"find newobj"`).

## ⚠️ Common Issues & Fixes
| Symptom | Likely Cause | Fix |
|---|---|---|
| **World fails to load** – black screen | Still using old `EXTERNPROTO` URLs | Replace with pure geometry (already done) |
