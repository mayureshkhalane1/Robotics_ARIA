# World Files Overview

## Available Worlds
| File | Description | Recommended Webots Version |
|------|-------------|-----------------------------|
| `house.wbt` | Simple house with sofa, table, cup, football, plant. | Works on all versions (R2023b‑R2025a). |
| `arena.wbt` | Open arena used for benchmark tests. | All versions. |
| `apartment.wbt` | **New pure VRML version** – a compact indoor apartment with searchable objects. | **R2025a** (loads with warning) **or any older version**. |

## Choosing a World
- **Quick demo / testing:** Use `arena.wbt`.
- **Realistic indoor scenario:** Use `apartment.wbt` (now compatible).
- **Extended indoor with more furniture:** Use `house.wbt`.

## Adding a New World
1. Create a new `.wbt` file under `src/webots/worlds/`.
2. Start with the header `#VRML_SIM R2023b utf8`.
3. Use only built‑in geometry nodes (`Box`, `Cylinder`, `Sphere`).
4. Add a `WorldInfo` and `Viewpoint`.
5. Define the ARIA robot (copy from `apartment.wbt`).
6. Add any additional objects (DEF‑named `Solid` nodes). 
7. Test by opening in the target Webots version.
